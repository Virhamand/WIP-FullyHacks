🎭 Imposter Game (AI vs Humans)

A real-time social deduction game where players try to identify the AI imposter hidden among them.

🧠 Concept

“Imposter Game” is an interactive multiplayer experience where 2 real players and 1 AI are placed into a shared session. All participants answer the same prompts, and players must determine which response was generated by AI.

The twist: AI is getting better—and spotting it isn’t as easy as it used to be.

🎮 Gameplay Overview
1. Matchmaking
Each game consists of:
2 human players
1 AI participant
Players are matched into a live session
2. Question Rounds (x3)

Each round follows this flow:

📝 Prompt Phase
All participants receive the same question
Players submit answers within:
A word limit
A time limit
👀 Reveal Phase
All responses are displayed anonymously
👉 Pointing Phase (Soft Accusation)
Players point to the response they suspect is AI
Players can attach a short explanation for their suspicion
This is NOT a vote—just gathering signals
3. Final Voting

After 3 rounds:

Players cast their final vote for who they believe is the AI
Outcomes:
✅ Humans win if majority correctly identify the AI
🤖 AI wins if it avoids detection
4. Tie-breaker (Optional)
If votes tie:
1 additional question round is played
Followed by another pointing + voting phase
⚙️ Key Design Challenges
🧩 Question Design

Bad questions can break the game.

Problem:

Questions like “How many ‘r’s are in strawberry?” make AI too easy to detect.

Solutions:

Curated prompt pool with constraints:
Open-ended
Opinion-based
Slightly ambiguous or subjective
Categories:
Personal experiences (fabricated but believable)
Preferences
Social reasoning
Creative responses
Optional:
Fetch real-world prompts (e.g., Reddit-style questions)
Filter using rules or AI moderation layer
⚖️ Balancing the AI

The AI should:

Not be too perfect
Not be too obviously robotic

Approaches:

Add slight randomness or imperfections
Inject human-like quirks:
Minor vagueness
Casual tone shifts
Occasional inconsistency
👥 Player Count Decision

Chosen: 2 Humans + 1 AI

Why:

Avoids vote ties common in 3v1 setups
Keeps gameplay fast and focused
Encourages stronger deduction
